# Mobile Responsive Upgrade

Replace only `app/globals.css` in the current project.

Then:
1. Commit
2. Push origin
3. Wait for Vercel Ready
4. Open orders.nexo.ge on the phone and refresh

What changes:
- On phones the permanent left sidebar becomes a fixed bottom navigation bar.
- Dashboard cards/filters stack cleanly.
- Status buttons scroll horizontally.
- Tables stay usable with horizontal swipe instead of breaking the page.
- Forms become one-column and touch-friendly.
- Inputs use 16px text to avoid unwanted iPhone zoom.
- Order details, products/variants and history are mobile-friendly.
- Desktop layout remains unchanged.
