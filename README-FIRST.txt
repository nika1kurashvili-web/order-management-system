ADMIN / OPERATOR განახლება

რას ამატებს:
- Admin: შეკვეთის სრული რედაქტირება და წაშლა.
- Operator: არსებული შეკვეთიდან მხოლოდ სტატუსისა და თრექინგ კოდის შეცვლა.
- შეზღუდვა დაცულია Supabase DB დონეზეც, არა მხოლოდ ღილაკებით.
- პროდუქტები: მარაგის გარეშე; Admin-ს შეუძლია აქტიური/არააქტიური.
- თანამშრომლები: Admin-ს შეუძლია role/active მართვა.
- ანალიტიკა: პერიოდი, შეკვეთები, გაყიდვები, ჩაბარებული, გაუქმება/დაბრუნება, TOP პროდუქტები, თანამშრომლების შედეგები.
- წინა ფუნქციები რჩება: თარიღის ფილტრი, Excel, თრექინგით ძებნა, მიტანის საფასური, ახალი სტატუსები.

ინსტალაცია:
1. Supabase > SQL Editor-ში გაუშვი supabase/admin_operator_security.sql ერთხელ.
2. თუ Success მიიღე, ZIP-ის app, lib და package.json ფაილები გადაიტანე პროექტში.
3. GitHub Desktop: Commit -> Push origin.
4. Vercel-ის deployment-ის დასრულების შემდეგ Ctrl+F5.
